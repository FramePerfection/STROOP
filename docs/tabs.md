# Understanding Tabs in STROOP

A "Tab" in STROOP effectively encapsulates a certain feature aspect of STROOP, and can be thought of as a module covering a certain topic or workflow that is usually based on STROOP's core functionality to read and write Super Mario 64's game memory.  
Some tabs have certain interactions between them, but those are usually not the key focus of any specific tab.

For a complete list of tabs and their documentation, see the [List of Tabs](#list-of-tabs).

By default, STROOP will show only a portion of all available tabs in the following order:

- Object
- Mario
- HUD
- Map
- Ghost
- Triangles
- Water
- File
- Camera
- Hacks
- M64
- Input
- Misc
- Custom
- TAS

This list is effectively a guess of what could be useful to someone who is just starting out with STROOP, but you can manage the tabs you want to see and their order (which is a setting that will be saved across sessions) using the controls in the center top area of the window:  

- The left and right pointing arrow buttons will move the currently selected tab left or right, respectively
- The `+`-Button will open a drop down menu that lets you select a currently hidden tab to show.
    - Note: The `Restore All Tabs` option will add all hidden tabs to the end of the list of shown tabs.
- Left clicking a tab header while holding down the `Ctrl` key will remove the tab from the shown tab list - you can then add it back with the `+`-Button, should you need it again.
